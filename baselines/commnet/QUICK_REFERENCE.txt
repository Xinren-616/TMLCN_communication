    --style seaborn-*      # 绘图风格

    ❌ 找不到日志文件？
       → ls train_tj_*_prune*.log
       → 使用正确的日期: --date 20260121
    
    ❌ 图表是空白的？
       → 检查日志文件是否完整
       → 确保训练至少到Epoch 100
    
    ❌ TEI图缺失？
       → 检查 saved/*/shapley_results/ 是否存在
       → 确保训练时使用了 --enable_shapley
    
    ❌ ModuleNotFoundError?
       → pip install matplotlib numpy
